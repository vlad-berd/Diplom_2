# API Test Automation — Stellar Burgers

Проект по автоматизации тестирования API сервиса Stellar Burgers.

👉 Основной фокус: проверка пользовательских сценариев и бизнес-логики API.

---

## 📌 О проекте

В проекте реализованы автотесты для ключевых сценариев:
- регистрация и авторизация пользователей  
- создание заказов  

Тестирование охватывает как позитивные, так и негативные сценарии.

---

## 🔧 Стек

- Python  
- Pytest  
- Requests  
- Allure  
- Faker  
- Postman  

---

## 🧪 Покрытие тестами

### 👤 Пользователь
- регистрация (валидные и невалидные данные)  
- проверка дубликатов  
- авторизация  

### 📦 Заказы
- создание заказа (с авторизацией и без)  
- валидация обязательных данных  
- обработка некорректных ингредиентов  

---

## ⚠️ Негативные сценарии

Проверены:
- отсутствие обязательных полей  
- несуществующие данные  
- некорректные входные параметры  

---

## 🧠 Подход к тестированию

- покрытие API позитивными и негативными сценариями  
- проверка не только статус-кодов, но и логики работы API  
- использование Faker для генерации уникальных данных  

---
